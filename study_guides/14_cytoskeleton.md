# 第14讲学习讲义：Cytoskeleton（细胞骨架）

对应课件：`Lecture_14.pptx.pdf`

这份讲义是给零基础同学用的。你不需要一开始就记住所有蛋白的名字，先抓住一条主线：**细胞骨架不是静态支架，而是一套可以快速重排的分子机器，它同时解决形态维持、内部运输、细胞运动和力学信号感知四大问题。**

## 这讲到底在讲什么

第14讲的核心不是背三类骨架的直径和组成，而是理解一个统一逻辑：

- 许多小亚基通过非共价相互作用聚合成线性聚合物。
- 聚合物具有极性和动态性。
- Accessory proteins 调控装配、解聚、交联和定位。
- Motor proteins 把化学能（ATP/GTP 水解）转成定向机械运动。
- 细胞的形态、运输、收缩和迁移由此产生。

如果你把这条主线抓住了，后面的具体细节都是这条线上的分支。

## 一、为什么细胞需要骨架

细胞内部是拥挤、柔软、动态的环境。如果只有膜和细胞质，细胞会难以维持形态，也无法把内部运输和空间分区组织起来。细胞骨架提供了三种核心能力：

- **支撑力**：抵抗外界拉伸和挤压，让细胞不会轻易塌陷。
- **轨道**：让 motor proteins 携带囊泡、细胞器和蛋白复合物定向移动。
- **可重塑结构**：在迁移、分裂、吞噬和形态变化时快速装配和解聚。

一句话概括：细胞骨架的共同逻辑是"小亚基聚合 -> 形成有极性的丝状结构 -> 调控蛋白和 motor proteins 赋予它功能"。

## 二、三类细胞骨架的功能分工

细胞骨架分为三大类，各有分工：

| 需求 | 主要骨架 | 典型例子 |
|---|---|---|
| 细胞表面变形 | Actin | lamellipodia、filopodia、胞吞、胞质分裂环 |
| 长距离运输 | Microtubule | ER/Golgi 定位、轴突运输、纺锤体 |
| 抗拉伸强度 | Intermediate filament | 皮肤角蛋白、核纤层、神经丝 |
| 细胞整体迁移 | Actin + microtubule + adhesion | 前缘突出、黏附形成、后缘收缩 |

注意：三类骨架不是各干各的，它们通过交联蛋白和信号通路紧密协作。

## 三、三类细胞骨架的结构详解

### 1. Actin filament（微丝）：细胞皮层和运动的核心

Actin 单体称为 **G-actin**（globular actin），聚合后形成 **F-actin**（filamentous actin）。每个 actin 单体都能结合 ATP 或 ADP，聚合时通常以 ATP-actin 加到纤维末端。

Actin filament 的结构特点：

- 由两条螺旋状 protofilament 缠绕形成，直径约 7 nm。
- 具有结构极性：**barbed end = + 端**（增长快），**pointed end = - 端**（增长慢）。
- 常集中在细胞皮层、微绒毛、应力纤维、迁移前缘和收缩环中。

Actin 的功能要从"推、拉、撑、割"四个字理解：

- **推**：前缘 actin 聚合推动膜向前，形成 lamellipodia。
- **拉**：myosin II 牵拉 actin 产生收缩力。
- **撑**：微绒毛内部 actin bundle 支撑突起，增加表面积。
- **割**：胞质分裂时 actin-myosin contractile ring 收缩，把两个子细胞分开。

### 2. Microtubule（微管）：细胞内长距离运输轨道

Microtubule 的基本单元是 **alpha/beta-tubulin heterodimer**。这些二聚体首尾相接形成 protofilament，通常 **13 条 protofilament** 围成中空管状结构，直径约 25 nm，是三类骨架中最粗的。

Microtubule 的结构特点：

- 具有结构极性：alpha-tubulin 暴露的一端通常是 - 端，beta-tubulin 暴露的一端是 + 端。
- + 端动态性强，- 端常锚定在 centrosome（中心体）或 microtubule-organizing center（MTOC）。
- beta-tubulin 上的 GTP 水解决定 microtubule 是否稳定。

Microtubule 的功能：

- 为 kinesin 和 dynein 提供运输轨道。
- 维持 ER、Golgi 等细胞器的空间分布。
- 形成有丝分裂纺锤体，牵引染色体分离。
- 构成纤毛和鞭毛的 axoneme，驱动流体运动或细胞运动。

### 3. Intermediate filament（中间纤维）：抗机械应力的绳索

Intermediate filament 的结构与 actin、microtubule 有根本不同。它的亚基先形成 **coiled-coil dimer**，再形成 **antiparallel tetramer**，进一步横向和纵向组装成绳索状纤维，直径约 10 nm。

关键特点：

- **没有明确的 + / - 端**，因此没有极性。
- **不依赖 ATP 或 GTP 水解**进行装配。
- 更稳定，主要提供机械强度。
- 具有组织特异性，因此也常用于病理诊断（如肿瘤来源鉴定）。

常见 intermediate filament 及其位置：

| 类型 | 主要位置 | 功能或意义 |
|---|---|---|
| Keratin | 上皮细胞 | 抵抗摩擦和拉伸，连接 desmosome / hemidesmosome |
| Vimentin | 间充质细胞 | 支持细胞形态和迁移 |
| Neurofilament | 神经元轴突 | 维持轴突直径 |
| Nuclear lamins（A、B、C） | 细胞核内侧 | 支持核膜，参与染色质组织 |

一个常考逻辑：上皮组织承受机械力时，力通过 desmosome 传给 keratin intermediate filament 网络，再跨细胞传播到组织层面。这解释了为什么 keratin 突变会导致皮肤脆弱疾病。

Intermediate filament 相关疾病超过 **50 种**，包括表皮松解症（epidermolysis bullosa simplex，keratin 突变）和 progeria（lamin A/C 突变导致早老症）。

## 四、细胞骨架的动态行为

### 1. 聚合的基本过程

细胞骨架聚合通常包括三个阶段：

1. **Nucleation（成核）**：少数单体形成稳定聚合核心，是最慢、最受调控的一步。
2. **Elongation（延伸）**：单体快速加到末端。
3. **Steady state（稳态）**：聚合与解聚达到动态平衡。

细胞常把调控重点放在 nucleation 上，因为一旦成核成功，纤维就能快速延长。

### 2. Actin treadmilling（踏车行为）

Actin filament 的 + 端和 - 端临界浓度不同。+ 端更容易加单体，- 端更容易丢单体。当游离 actin 浓度处在两端临界浓度之间时，会出现：

```text
+ 端持续加 ATP-actin
纤维内部 ATP 水解为 ADP
- 端持续释放 ADP-actin
整体长度可近似不变，但亚基在"流动"
```

这就是 **treadmilling**。它让细胞能在保持局部结构的同时不断更新 actin 网络，是一种"旧的不去、新的不来"的动态平衡。

### 3. Microtubule dynamic instability（动态不稳定性）

Microtubule 的动态不稳定性由 **GTP cap** 控制。这是考试高频考点，记成一个判断题：

- 新加入的 tubulin 带 GTP。
- 聚合后 beta-tubulin 上的 GTP 会水解为 GDP。
- 如果 + 端仍保留 GTP-tubulin cap，microtubule 稳定并继续增长。
- 如果 GTP 水解追上了聚合速度，GTP cap 消失，GDP-tubulin 构象偏弯曲，microtubule 快速解聚，这叫 **catastrophe（灾变）**。
- 如果重新获得 GTP cap，就会发生 **rescue（拯救）**，重新增长。

```text
GTP cap 在 -> 增长/稳定
GTP cap 丢失 -> catastrophe
重新获得 GTP cap -> rescue
```

### 4. Intermediate filament 的动态调控

Intermediate filament 比前两者稳定，但不是完全不变。典型调控方式是 **phosphorylation（磷酸化）**。

例子：有丝分裂时 nuclear lamins 被磷酸化，核纤层解体，核膜破裂；分裂结束后去磷酸化，核纤层重新组装。

## 五、Accessory proteins 如何调控骨架

### 1. Actin-binding proteins

Actin 的功能几乎都需要 actin-binding proteins 参与。这是考试重点，需要按功能分类记忆：

| 蛋白 | 作用 | 记忆方式 |
|---|---|---|
| Arp2/3 complex | 在已有 actin 侧面成核，形成约 70 度分支网络 | lamellipodia 的分支 actin |
| Formin | 促进不分支直线 actin 生长，黏在 + 端连续加入单体 | filopodia、应力纤维、收缩环 |
| Profilin | 促进 ADP-actin 换 ATP，并把单体送到 + 端 | 帮助增长 |
| Thymosin beta4 | 结合 actin 单体，阻止聚合 | 暂存单体的"仓库" |
| Cofilin | 结合 ADP-actin 区域，促进切割和解聚 | 加速更新 |
| Capping protein | 盖住末端，阻止继续生长或缩短 | 封端 |
| Gelsolin | Ca2+ 调控的切割和封端蛋白 | 快速重塑 |
| Fimbrin / Fascin | 形成紧密平行 actin bundle | 微绒毛、filopodia |
| alpha-actinin | 形成较疏松 bundle | stress fibers |
| Spectrin | 红细胞膜骨架的主体 | 维持红细胞双凹盘形态 |
| Filamin | 交联成网状 actin gel | 细胞皮层 |
| Dystrophin | 连接 actin 与膜上的 dystroglycan 复合体 | 肌肉中传递力到 ECM |

**分支网络和直线束的区别非常重要**：

- **Arp2/3**：从已有纤维侧面长出约 70 度分支，适合推平的膜片（lamellipodia）。
- **Formin**：黏在 + 端，连续加入 actin，适合长直纤维（filopodia、stress fibers）。

### 2. Microtubule-associated proteins（MAPs）

Microtubule 的调控蛋白包括：

- **gamma-TuRC**：在 centrosome 中帮助 microtubule 成核，是微管组织的核心。
- **MAPs（如 MAP2）**：稳定 microtubules，调节间距和组织。
- **Tau**：神经元轴突中稳定 microtubules；异常聚集与阿尔茨海默病等神经退行性疾病有关。
- **Katanin**：切割 microtubules，帮助重排。
- **+TIPs**：结合 microtubule + 端，调控增长端与细胞皮层或黏附结构的连接。

### 3. Intermediate filament-associated proteins

Intermediate filaments 常通过连接蛋白与细胞连接、微管和 actin 网络整合：

- **Plectin**：把 intermediate filaments 连接到 microtubules、actin 和黏附结构，是"万能连接器"。
- **Desmoplakin**：在 desmosome 中把 cadherin 复合体连接到 keratin。
- **Lamin-binding proteins**：把 nuclear lamina 与核膜、染色质联系起来。

### 4. 答题套路：遇到"某蛋白如何影响细胞骨架"的题

可以按四类回答：

1. 是否影响 **nucleation（成核）**。
2. 是否影响 **elongation / capping（延伸/封端）**。
3. 是否影响 **severing / depolymerization（切割/解聚）**。
4. 是否影响 **bundling / crosslinking / anchoring（成束/交联/锚定）**。

## 六、Motor proteins：把化学能变成运动

### 1. Motor protein 的共同工作方式

Motor proteins 把 ATP 水解能转成定向运动。它们通常有三个功能域：

- **Motor domain**：结合轨道并水解 ATP。
- **Coiled-coil 或 linker**：传递构象变化。
- **Cargo-binding tail**：结合货物、膜泡或其他结构。

核心循环：

```text
ATP 结合 -> motor 与轨道亲和力改变
ATP 水解 -> 构象预备
Pi/ADP 释放 -> power stroke（动力冲程）
循环重复 -> 方向性运动
```

### 2. Myosin：actin-based motor proteins

Myosin 大多沿 actin filament 向 **+ 端运动**。Myosin 家族有超过 **40 个成员**，不同类型的 myosin 做不同工作：

| Myosin 类型 | 功能 |
|---|---|
| Myosin II | 肌肉收缩、应力纤维、胞质分裂收缩环 |
| Myosin V | 沿 actin 运输囊泡和细胞器 |
| Myosin I | 连接膜和 actin，参与膜形态调节 |

### 3. 肌肉收缩的 actin-myosin 机制

骨骼肌的基本单位是 **sarcomere（肌节）**：

- Actin thin filament 从 Z disc 向中间伸出。
- Myosin thick filament 位于中间（M line）。
- Myosin head 周期性结合 actin 并产生 power stroke。
- Sarcomere 缩短，但 actin 和 myosin filament 本身长度不变（滑丝模型）。

收缩调控依赖 Ca2+：

1. 神经信号引起肌浆网释放 Ca2+。
2. Ca2+ 结合 troponin（肌钙蛋白）。
3. Tropomyosin（原肌球蛋白）从 actin 的 myosin-binding site 上移开。
4. Myosin head 可以结合 actin，产生收缩。

**常考点**：ATP 对肌肉不只提供能量，也负责让 myosin 从 actin 上解离。死亡后 ATP 耗尽，myosin 不能脱离 actin，会出现 **rigor mortis（尸僵）**。

### 4. Kinesin：microtubule-based motor，向 + 端运动

Kinesin 多数沿 microtubule 向 **+ 端运动**。在典型动物细胞中，microtubule - 端靠近 centrosome，+ 端朝向细胞周边，所以 kinesin 常负责向外周运输（anterograde transport）。

典型功能：

- 把分泌囊泡、膜蛋白、细胞器运向细胞周边。
- 在神经元轴突中进行 anterograde transport（从胞体到突触末梢）。
- 有丝分裂中推动纺锤体微管滑动。

### 5. Dynein：microtubule-based motor，向 - 端运动

Dynein 通常沿 microtubule 向 **- 端运动**，因此常负责向 centrosome 或细胞中心运输（retrograde transport）。步长约 **8 nm**。

典型功能：

- Endosome、lysosome 等向细胞中心运输。
- 神经元中的 retrograde transport（从末梢回到胞体）。
- 纤毛和鞭毛中产生 microtubule 滑动。
- 参与纺锤体定位和染色体运动。

Dynein 本身巨大且复杂，常需要 **dynactin** 复合体帮助连接 cargo 并增强运动过程性（processivity）。

### 6. Kinesin vs Dynein 速记

| 对比 | Kinesin | Dynein |
|---|---|---|
| 轨道 | Microtubule | Microtubule |
| 运动方向 | 向 + 端（外周） | 向 - 端（中心） |
| 运输类型 | Anterograde | Retrograde |
| 辅助因子 | 通常不需要 | 需要 dynactin |
| 步长 | 约 8 nm | 约 8 nm |

## 七、Cilia 和 Flagella：纤毛与鞭毛

运动性纤毛和鞭毛的核心结构常是 **9+2 axoneme**：

- 9 组外周 microtubule doublets。
- 中央 2 条 microtubules。
- Dynein arms 让相邻 doublets 发生滑动。
- 因为有连接结构（nexin links）限制，滑动转化为弯曲摆动。

非运动性 **primary cilium** 常是信号感受结构，参与 Hedgehog 等通路。它依赖 **intraflagellar transport（IFT）** 把蛋白运入和运出纤毛。

纤毛功能障碍导致的疾病统称 **ciliopathies**，包括多囊肾、视网膜退行性变、不孕等。

## 八、细胞迁移机制

### 1. 迁移的四步循环

一个贴壁细胞向前迁移通常包括：

1. **前缘突出（Protrusion）**：actin 聚合推动膜形成 lamellipodia 或 filopodia。
2. **形成新黏附（Adhesion）**：integrin 与 ECM 结合，形成 focal adhesion。
3. **细胞体前移（Translocation）**：actin-myosin 收缩把细胞体拉向前方。
4. **后缘脱附（Retraction）**：旧黏附解离，细胞尾部收回。

这个循环不是单纯 actin 的事情，还需要 microtubules 参与极性建立、运输膜泡和调控黏附更新。

### 2. Rho family GTPases：迁移的信号开关

细胞迁移中最核心的三类小 GTPase：

| GTPase | 主要输出 | 结果 |
|---|---|---|
| Cdc42 | filopodia、细胞极性 | 探路 |
| Rac | lamellipodia、Arp2/3 分支 actin | 向前铺展 |
| Rho | stress fibers、myosin II 收缩、focal adhesion 成熟 | 牵拉和张力 |

它们像开关一样在 GTP-bound active 和 GDP-bound inactive 状态间切换：

- **GEF**（鸟苷酸交换因子）：激活，促进 GDP 换 GTP。
- **GAP**（GTP酶激活蛋白）：失活，促进 GTP 水解为 GDP。
- **GDI**（鸟苷酸解离抑制因子）：抑制并帮助在细胞内转运。

### 3. Focal adhesion 的功能

Focal adhesion 是细胞迁移中的力学和信号平台：

```text
ECM
  -> integrin（跨膜受体）
  -> talin / kindlin / vinculin / paxillin / FAK（胞内适配和信号蛋白）
  -> actin stress fibers（力的执行结构）
```

功能：

- 把 actin 产生的力传给 ECM。
- 感受 ECM 硬度（mechanosensing）。
- 激活 FAK、Src、Rho GTPase 等信号通路。
- 在迁移时不断形成和解离，是动态结构。

### 4. 细胞迁移的答题模板

```text
外界信号
 -> PI3K / Rho GTPases 建立前后极性
 -> 前缘 actin 聚合产生 protrusion
 -> integrin 形成新 focal adhesion
 -> myosin II 收缩牵引细胞体
 -> 后缘黏附解离
 -> microtubules 运输膜和调控极性
```

## 九、考前速记版

| 系统 | 单体 | 直径 | 极性 | 能量核苷酸 | 主要功能 |
|---|---|---:|---|---|---|
| Actin filament | G-actin | 约 7 nm | 有 + / - 端 | ATP | 细胞皮层、肌肉收缩、细胞迁移、胞质分裂 |
| Microtubule | alpha/beta-tubulin heterodimer | 约 25 nm | 有 + / - 端 | GTP | 细胞器运输、纺锤体、纤毛鞭毛、细胞极性 |
| Intermediate filament | 多种 IF 蛋白 | 约 10 nm | 无明显极性 | 不依赖 ATP/GTP | 抗机械拉伸、核纤层、组织特异性支撑 |

最容易混的点：

- **Actin 和 microtubule 都有极性**，所以能和方向性 motor proteins 配合。
- **Intermediate filament 没有明确极性**，主要做机械强度，不承担典型轨道运输。
- **Actin 是 ATP-actin 聚合，microtubule 是 GTP-tubulin 聚合**。
- **Microtubule 的 dynamic instability 来自 GTP cap 的有无**。
- **Actin treadmilling 来自两端 critical concentration 不同**。
- **Myosin 多数沿 actin 向 + 端运动**；kinesin 多数沿 microtubule 向 + 端运动；dynein 向 - 端运动。
- **Rigor mortis 的原因**：ATP 耗尽，myosin 无法从 actin 上解离。

## 十、关键词

- **G-actin / F-actin**：球状 actin 单体 / 纤维状 actin 聚合物。
- **Barbed end / Pointed end**：actin filament 的 + 端 / - 端。
- **Treadmilling**：actin 在 + 端聚合、- 端解聚的动态平衡现象。
- **Dynamic instability**：microtubule 因 GTP cap 有无而出现的增长与快速解聚交替现象。
- **Catastrophe / Rescue**：microtubule 丢失 GTP cap 快速解聚 / 重新获得 GTP cap 恢复增长。
- **GTP cap**：microtubule + 端尚未水解的 GTP-tubulin 层，维持微管稳定。
- **Arp2/3 complex**：促进 actin 分支成核的关键复合物。
- **Formin**：促进 actin 直线延伸的成核蛋白。
- **Sarcomere**：骨骼肌的基本收缩单位。
- **Rigor mortis**：死后 ATP 耗尽导致的肌肉僵硬。
- **Kinesin**：沿 microtubule 向 + 端运动的 motor protein。
- **Dynein**：沿 microtubule 向 - 端运动的 motor protein，需要 dynactin 辅助。
- **Rho GTPase family**：Cdc42、Rac、Rho，调控细胞极性和迁移的信号开关。
- **Focal adhesion**：integrin 介导的细胞-ECM 黏附结构，力学和信号平台。
- **Ciliopathy**：纤毛功能障碍导致的疾病。

## 十一、常见误区

- "Intermediate filament 也像 actin 和 microtubule 一样有极性"是错的。IF 没有明确极性，不依赖核苷酸水解装配。
- "Kinesin 和 dynein 都沿 microtubule 向同一方向运动"是错的。Kinesin 向 + 端，dynein 向 - 端。
- "Motor protein 直接消耗 GTP"通常不准确。Myosin、kinesin、dynein 都消耗 ATP（微管本身的 dynamic instability 才涉及 GTP）。
- "Rigor mortis 是因为 ATP 过多"是错的。恰恰相反，是因为 ATP 耗尽，myosin 无法从 actin 上解离。
- "Arp2/3 和 formin 做的事差不多"不准确。Arp2/3 产生分支网络（lamellipodia），formin 产生直线束（filopodia、stress fibers），形态和功能完全不同。
- "细胞迁移只靠 actin"是错的。迁移需要 actin（前缘推进和收缩）、microtubule（极性和运输）、integrin（黏附）和 Rho GTPase（信号）协同。
- "Intermediate filament 完全不变"不准确。IF 可通过磷酸化调控，如 nuclear lamins 在有丝分裂时解体。

## 十二、自测题

1. 为什么 microtubule 会发生 dynamic instability，而 intermediate filament 不会以同样方式发生？

答题关键：microtubule 依赖 GTP 水解，GDP-tubulin 构象偏弯曲导致不稳定；intermediate filament 不依赖核苷酸水解，装配机制不同。

2. Arp2/3 和 formin 都能促进 actin 聚合，它们产生的网络形态有什么不同？

答题关键：Arp2/3 从已有纤维侧面成核产生约 70 度分支网络（适合 lamellipodia）；formin 在 + 端连续加入单体产生直线束（适合 filopodia 和 stress fibers）。

3. 如果一个细胞中 cofilin 活性过高，actin 网络会发生什么变化？

答题关键：cofilin 切割 ADP-actin 区域，活性过高会导致 actin 纤维过度解聚，网络变少，但也加速单体回收再利用。

4. 为什么 kinesin 和 dynein 能在同一条 microtubule 上产生相反方向的运输？

答题关键：它们的 motor domain 结构不同，对 microtubule 的极性识别相反。Kinesin 识别 + 端方向，dynein 识别 - 端方向。

5. 贴壁细胞迁移时，actin、myosin、integrin 和 Rho GTPase 分别承担什么角色？

答题关键：actin 推动前缘突出；myosin II 收缩牵引细胞体；integrin 形成 focal adhesion 连接 ECM；Rho GTPase（Cdc42/Rac/Rho）建立极性并调控各步骤。

6. 为什么说 ATP 对肌肉收缩不只提供能量？

答题关键：ATP 水解提供 power stroke 的能量，但 ATP 结合本身也负责让 myosin 从 actin 上解离。没有 ATP，myosin 会永久锁在 actin 上（rigor mortis）。

7. Intermediate filament 为什么常用于病理诊断中的肿瘤分类？

答题关键：IF 具有组织特异性表达，不同细胞类型表达不同的 IF 蛋白（如上皮表达 keratin，间充质表达 vimentin），因此可以通过 IF 染色判断肿瘤来源。
