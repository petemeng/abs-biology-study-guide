## 一、肿瘤的本质：什么是肿瘤

### 1. 肿瘤的定义

肿瘤细胞有两个可遗传的核心特性，缺一不可：

- **不顾正常生长限制地增殖**——该停的时候不停。
- **侵袭并定植于其他细胞的领地**——跑到不该去的地方。

只满足第一条的叫良性肿瘤（benign tumor）；两条都满足的叫恶性肿瘤（malignant tumor），也就是我们通常说的"癌症"。

### 2. 良性肿瘤 vs 恶性肿瘤

| 特征 | 良性肿瘤（Benign） | 恶性肿瘤（Malignant） |
|------|-------------------|---------------------|
| 是否致癌 | 否 | 是 |
| 包膜 | 有包膜，不扩散 | 无包膜 |
| 生长速度 | 慢 | 快 |
| 侵袭性 | 无 | 有 |
| 转移 | 不转移 | 可转移 |
| 细胞形态 | 基本正常 | 核大、深染、形态异常 |

关键区分点：**有无侵袭和转移能力**。良性肿瘤虽然也会增大，但它待在原地不跑；恶性肿瘤会突破基底膜、进入血管、跑到远处器官扎根。

### 3. 肿瘤的发展阶段

上皮来源的肿瘤（最常见的一类）有一个经典的渐进发展过程：

```
正常上皮 → 增生（Hyperplasia）→ 非典型增生（Atypical hyperplasia）
→ 原位癌（Carcinoma in situ）→ 微小浸润（Microinvasive）
→ 恶性肿瘤（Malignant tumor）
```

每一步都对应更多突变的积累和更多正常控制机制的丧失。

### 4. 原发肿瘤与转移瘤

- **原发肿瘤（Primary tumor）**：肿瘤最初发生的地方。
- **转移瘤（Metastasis）**：从原发肿瘤"播种"到其他器官的新肿瘤。

时间尺度上，原发肿瘤从单细胞长到 1 cm 可能需要约 12 年，但形成转移可能只要几个月。

转移是肿瘤致死的主要原因——约 90% 的肿瘤死亡来自转移而非原发瘤。

### 5. 肿瘤按组织来源分类

| 类型 | 英文 | 来源 | 例子 |
|------|------|------|------|
| 癌 | Carcinoma（最常见） | 上皮细胞 | 肺癌、乳腺癌、肠癌 |
| 肉瘤 | Sarcoma | 骨头、软组织 | 骨肉瘤 |
| 骨髓瘤 | Myeloma | 浆细胞 | 多发性骨髓瘤 |
| 白血病 | Leukemia | 血细胞（骨髓来源） | 急/慢性白血病 |
| 淋巴瘤 | Lymphoma | 淋巴系统 | 霍奇金淋巴瘤、非霍奇金淋巴瘤 |

### 6. 肿瘤的临床分期

| 分期 | 描述 |
|------|------|
| 0 期 | 原位癌（Carcinoma in situ）——最早期 |
| I 期 | 局部，肿瘤较小 |
| II 期 | 早期局部进展 |
| III 期 | 晚期局部进展 |
| IV 期 | 已发生远处转移（Metastasized） |

## 二、单克隆起源：大多数肿瘤来自一个异常细胞

### 核心观点

绝大多数肿瘤是**单克隆起源（monoclonal origin）**的——也就是说，一个肿瘤里所有的癌细胞都是同一个"祖先细胞"分裂出来的后代。

### 证据一：染色体易位——费城染色体

慢性髓性白血病（CML）中，所有肿瘤细胞都携带相同的**费城染色体（Philadelphia chromosome）**：

- 这是 9 号染色体和 22 号染色体之间的**相互易位（reciprocal translocation）**
- 形成 9q+ 和 22q-（即费城染色体）
- 所有癌细胞都有同一种易位 → 它们来自同一个祖先细胞

### 证据二：X 染色体失活嵌合

- 女性每个细胞会随机失活一条 X 染色体（来自父亲的 Xp 或母亲的 Xm）
- 正常组织应该是 Xp 失活和 Xm 失活的细胞混在一起的"嵌合花纹"
- 但**肿瘤组织内所有细胞都失活同一条 X**——说明它们都来自同一个细胞

### 体细胞突变的累积

一般需要**多个突变（multiple mutations）**才能让一个正常细胞变成肿瘤细胞：

```
正常细胞 → 第1个突变 → 开始异常增殖 → 第2个突变 → 更危险
→ 第3个突变 → ... → 肿瘤
```

这就是为什么**肿瘤发病率随年龄指数级上升**——年纪越大，累积的突变越多。肿瘤发病率与年龄的关系图呈指数型上升曲线。

### 肿瘤是微进化过程

肿瘤发展本质上是一个**微进化（microevolutionary）过程**：

```
正常上皮 → 低度上皮内瘤变 → 高度上皮内瘤变 → 浸润性癌
```

每一步都是**随机突变 + 自然选择**——生长更快、更能逃避免疫的克隆胜出。这就是为什么肿瘤治疗如此困难——它是一个不断进化的细胞群体。

## 三、肿瘤的七大特征（7 Hallmarks of Cancer）

这是本讲的核心内容，也是考试重点。七大特征可以记成口诀**"不稳分代死老转血"**。

| 序号 | 特征 | 核心机制 |
|------|------|---------|
| 1 | 遗传和表观遗传**不稳定** | 多倍体、非整倍体、易位、染色体碎裂 |
| 2 | **不该分裂时分裂** | 接触抑制丧失、细胞周期失控 |
| 3 | 异常代谢（**Warburg 效应**） | 偏向有氧糖酵解 |
| 4 | **异常应激反应** | 凋亡减少 |
| 5 | 逃避**复制衰老** | 激活端粒酶或替代性端粒维持 |
| 6 | **侵袭与转移** | 突破基底膜、血道播散 |
| 7 | 高**血管生成**活性 | 分泌 VEGF 等促血管因子 |

### 特征 1：基因组不稳定（Genomic instability）

肿瘤细胞的基因组极不稳定，表现为：

- **多倍体（Polyploidy）**：染色体整套增多（3n、4n）
- **非整倍体（Aneuploidy）**：染色体数目异常
- **易位（Translocations）**：染色体片段交换
- **染色体碎裂（Chromothripsis）**：染色体在一次事件中"粉碎"再重组——肿瘤特有的剧烈基因组事件

发生机制：有丝分裂时**滞后染色体（lagging chromosome）**可能被包进微核（micronucleus），微核中的染色体可能被"粉碎"，这就是 chromothripsis 的起源。

### 特征 2：细胞分裂失控

| 现象 | 正常细胞 | 肿瘤细胞 |
|------|---------|---------|
| 接触抑制 | 接触后停止分裂，形成单层 | 失去接触抑制，堆积成灶（foci） |
| 形态 | 整齐排列 | 紊乱、纺锤形、堆叠 |

在培养皿中，转化的细胞会失去接触抑制，形成"集落"（foci），这是经典的细胞转化标志。

### 特征 3：Warburg 效应（异常糖代谢）

**正常分化细胞：**
```
葡萄糖 → 糖酵解 → 丙酮酸 → 氧化磷酸化 → 大量 ATP + CO2 + H2O
```

**肿瘤细胞：**
```
葡萄糖 → 增强的糖酵解 → 丙酮酸 → 大量乳酸（lactate）
                              ↓
                    同时也产生大量合成 DNA、蛋白、脂质的"building blocks"
```

为什么肿瘤要这么做？

- 氧化磷酸化效率高（产约 36 ATP）但慢且需要氧气
- 糖酵解效率低（产 2 ATP）但快，且中间产物可以用来合成大分子
- 肿瘤需要快速增殖，宁可牺牲能量效率，也要快速获取合成原料

临床应用：PET-CT 用 18F-FDG（带放射性的葡萄糖类似物）让肿瘤显影——因为肿瘤葡萄糖摄取异常旺盛。

### 特征 4：异常应激反应（凋亡减少）

| 情况 | 增殖 | 凋亡 | 结果 |
|------|------|------|------|
| 正常 | 正常 | 正常 | 稳态（Homeostasis） |
| 异常 A | 增强 | 正常 | 肿瘤 |
| 异常 B | 正常 | 减弱 | 肿瘤 |

关键点：**凋亡减少和增殖增强一样致命**。即使分裂速度正常，只要该死的细胞不死，就会堆积成肿瘤。

### 特征 5：逃避复制衰老

正常细胞每次分裂端粒都会变短，短到一定程度就会触发复制衰老（senescence）或 DNA 损伤反应，停止分裂。这是一道天然的"抗癌防线"。

肿瘤细胞通过两种方式绕过这道防线：

- 大多数（约 90%）重新激活**端粒酶（hTERT）**
- 少数通过**替代性端粒延长（ALT）通路**
- 结果：**永生化（immortalization）**

```
正常细胞 → 致癌突变 + 端粒缩短 → 应激反应：
   ├── 如果衰老反应正常 → 良性肿瘤（细胞停止分裂）
   └── 如果衰老反应缺陷 + 端粒酶重新激活 → 恶性肿瘤
```

### 特征 6：侵袭与转移

转移过程（要背）：

```
1. 正常上皮 → 良性肿瘤
2. 肿瘤细胞获得侵袭能力 → 突破基底膜
3. 进入毛细血管 → 通过血流播散
4. 大部分细胞死亡（不到千分之一存活）
5. 存活细胞黏附远端血管壁
6. 穿出血管，形成微转移
7. 增殖、血管化 → 完整转移灶
```

### 特征 7：血管生成（Angiogenesis）

- 肿瘤生长超过 1-2 mm 后必须建立自己的血管供应（否则缺氧坏死）
- 通过分泌 **VEGF（血管内皮生长因子）** 等诱导新血管形成
- 新血管也是肿瘤细胞进入血流转移的通道

## 四、肿瘤关键基因（Cancer-Critical Genes）

### 1. 三类肿瘤关键基因

| 类别 | 突变类型 | 比喻 |
|------|---------|------|
| **癌基因（Oncogene）/ 原癌基因（Proto-oncogene）** | 功能获得（Gain of function） | 油门卡死 |
| **抑癌基因（Tumor suppressor）** | 功能丧失（Loss of function） | 刹车失灵 |
| **基因组维护基因（Genome maintenance genes）** | DNA 修复缺陷 | 修理工罢工 |

经典类比：肿瘤就是一辆失控的车——油门（癌基因）卡在最大档，刹车（抑癌基因）失灵，修理工（DNA 修复基因）罢工。三者都会让车失控。

### 2. 癌基因 vs 抑癌基因：关键区别

| 特征 | 癌基因（Oncogene） | 抑癌基因（Tumor suppressor） |
|------|-------------------|---------------------------|
| 突变类型 | 功能获得（Gain of function） | 功能丧失（Loss of function） |
| 需要几个等位基因突变 | **1 个**（单个突变即足） | **2 个都要失活**（两次打击） |
| 显隐性 | 显性 | 隐性 |
| 比喻 | 油门卡死 | 刹车失灵 |

### 3. 原癌基因（Proto-oncogene）的概念

原癌基因是**正常细胞中存在的、调控细胞增殖和存活的基因**。它们正常时不会触发肿瘤，但一旦被异常激活或过表达，就会变成致癌的癌基因（oncogene）。

这个概念来源于 Rous 肉瘤病毒（RSV）的研究：

- RSV 的基因组中包含一个 **src 基因**，编码 Src 蛋白酪氨酸激酶
- 后来发现，宿主细胞（鸡）的基因组中也有一个同源的 **c-Src 基因**（原癌基因）
- 病毒"偷"了宿主的原癌基因并改造成了致癌版本（v-Src）

### 4. 原癌基因如何被激活成癌基因？（四种方式）

```
                  proto-oncogene（正常的）
        ┌─────────────┬──────────────┬───────────────┐
        ↓             ↓              ↓               ↓
  点突变/缺失      调控区突变      基因扩增         染色体重排
（编码区改变）   （表达量上调）  （拷贝数增多）   （融合到强启动子下游）
        ↓             ↓              ↓               ↓
  超活性蛋白      正常蛋白         正常蛋白       超活性融合蛋白
 （量正常）      （量大增）       （量大增）      （新功能或失控）
```

**典型例子：**

**(1) 点突变——Ras 基因**
- Ras 是 GTP 酶，正常情况下水解 GTP 关闭信号
- 点突变（如 G12V）让 Ras 锁定在 GTP 结合的"激活"态 → 持续促进生长信号

**(2) 截短——EGFR 突变**
- 正常 EGFR 需要 EGF 配体才能二聚化、激活
- 截短的 EGFR（缺失胞外配体结合区）无需配体即可持续激活
- 临床联系：肺癌中常见 EGFR 突变，靶向药如吉非替尼（gefitinib）

**(3) 基因扩增——HER2/ERBB2**
- 乳腺癌中常见 HER2 拷贝数扩增 → HER2 过表达 → 持续生长信号
- 靶向药：赫赛汀（Trastuzumab）

**(4) 染色体易位——BCR-ABL（费城染色体）**
- 9 号 ABL + 22 号 BCR → 融合基因 BCR-ABL
- 编码一个持续活跃的酪氨酸激酶 → 慢性髓性白血病
- 靶向药：伊马替尼（Imatinib，格列卫）——肿瘤靶向治疗的里程碑

### 5. 抑癌基因（Tumor Suppressors）

抑癌基因的功能是**抑制细胞过度增殖、修复 DNA、诱导凋亡**。一旦双等位基因都失活，肿瘤就失去了刹车。

**经典抑癌基因：**

| 基因 | 全名 | 功能 | 相关肿瘤 |
|------|------|------|----------|
| **Rb** | Retinoblastoma | 抑制 E2F，控制 G1/S 进展 | 视网膜母细胞瘤 |
| **p53** | TP53，"基因组的守护者" | DNA 损伤响应，激活 p21，诱导凋亡 | 超过 50% 的肿瘤有 p53 突变 |
| **ARF** | — | 稳定 p53 | 多种肿瘤 |
| **Tsc1** | 结节性硬化复合物 1 | 抑制 mTOR | 结节性硬化症 |
| **NF1** | 神经纤维瘤蛋白 1 | 抑制 Ras | 神经纤维瘤病 |

### 6. Rb 基因与"二次打击"假说

**Rb 通路：**
```
活性 Rb + E2F → E2F 被抑制 → 细胞不进入 S 期

外界生长信号 → 激活 G1-Cdk → 磷酸化 Rb → Rb 失活 → E2F 释放
   → 转录 S 期基因 → 激活 S-Cdk → DNA 合成
```

Rb 的"二次打击"假说（Two-hit hypothesis，Knudson）：

| 情况 | 第 1 个 Rb 拷贝 | 第 2 个 Rb 拷贝 | 结果 |
|------|---------------|---------------|------|
| 正常人 | 正常 | 正常 | 偶尔一个细胞突变一个拷贝，不影响 → 无肿瘤 |
| 遗传性 | 生来就突变（遗传） | 偶尔细胞突变（高概率） | 常发病，常双眼多个肿瘤 |
| 散发性 | 正常 | 同一细胞两次突变（极低概率） | 大龄、单侧、单个肿瘤 |

这解释了为什么家族遗传性患者很小就发病、双眼都有肿瘤，而散发型都是大龄、单侧、单个肿瘤。

### 7. p53——"基因组的守护者"

**p53 介导的 DNA 损伤响应通路：**

```
DNA 双链断裂（X射线/紫外线/化学损伤）
   ↓
ATM/ATR 激酶激活
   ↓
Chk1/Chk2 激酶激活
   ↓
磷酸化 p53（磷酸化的 p53 不被 Mdm2 降解 → 稳定活化）
   ↓
p53 进核，激活 p21 基因转录
   ↓
p21（Cdk 抑制剂）结合 G1/S-Cdk 和 S-Cdk
   ↓
细胞周期停滞在 G1/S 和 G2/M → 有时间修复 DNA
```

如果 DNA 损伤过重、无法修复：
- p53 诱导凋亡基因表达（如 Bax、PUMA）
- 细胞自杀，避免突变细胞继续繁殖

p53 失活的后果：损伤的细胞继续分裂 → 突变累积 → 癌症。这就是为什么 p53 在超过 50% 的肿瘤中失活。

### 8. 抑癌基因失活的多种方式

抑癌基因的失活不一定是基因突变，还可以是**表观遗传沉默**：

- 两条染色体上都是基因突变
- 两条染色体上都是表观遗传沉默（如 DNA 甲基化）
- 一个突变 + 一个沉默

以上任何组合都能导致功能完全丧失 → 肿瘤。这就是为什么去甲基化药物（如 5-氮杂胞苷）也能治疗某些肿瘤——恢复被沉默的抑癌基因。

## 五、肿瘤的成因

### 四大类成因

| 类别 | 说明 |
|------|------|
| 生活方式（Lifestyle） | 吸烟、饮食、运动、肥胖 |
| 环境（Environment） | 地区差异、移民研究 |
| 致癌物（Carcinogen） | 化学物质、辐射 |
| 致癌病毒（Cancer-causing virus） | HPV、HBV、EBV 等 |

### 生活方式

主要可改变因素：

- 吸烟 → 肺癌（占癌死亡 29%，75% 可避免）
- 过量饮食动物脂肪
- UV 暴露 → 皮肤癌
- 肥胖 → 多种肿瘤
- 多吃水果蔬菜、规律运动 → 降低风险

肥胖促癌的机制：

1. 促炎细胞因子分泌增加（IFN-gamma、IL-6、TNF-alpha）
2. 脂肪因子调节失常（leptin 增高、adiponectin 降低）
3. 免疫细胞浸润和功能异常（T 细胞"累瘫"→ 肿瘤细胞趁虚而入）

### 致癌物（Carcinogens）

| 类别 | 例子 |
|------|------|
| 化学物质 | 黄曲霉毒素 B1、苯并芘、苯、砷、石棉 |
| 辐射 | 紫外线（UV）、X 射线、gamma 射线 |

很多致癌物是**前致癌物（procarcinogen）**，需要在体内经代谢"激活"才致癌。例如黄曲霉毒素 B1 经细胞色素 P-450 酶代谢后生成活性致癌物，与 DNA 中的鸟嘌呤结合形成加合物 → 突变 → 肝癌。

### 致癌病毒和细菌

| 病原体 | 相关肿瘤 |
|--------|---------|
| HPV（人乳头瘤病毒） | 宫颈癌（已有疫苗） |
| HBV（乙肝病毒） | 肝癌（已有疫苗） |
| EBV（EB 病毒） | Burkitt 淋巴瘤、鼻咽癌 |
| H. pylori（幽门螺杆菌） | 胃癌（唯一被 WHO 列为 Group 1 致癌物的细菌） |

HPV 和 HBV 疫苗是预防癌症的重要进展——疫苗预防感染 → 预防肿瘤。

## 六、ECM 与肿瘤转移的关联

### ECM 降解是肿瘤转移的关键步骤

肿瘤细胞要转移，必须突破基底膜和周围 ECM。这依赖于蛋白酶对 ECM 的降解：

| 降解酶 | 全名 | 特点 |
|--------|------|------|
| **MMPs** | 基质金属蛋白酶 | 依赖 Ca2+ 或 Zn2+ |
| **丝氨酸蛋白酶** | Serine protease | 用活性中心丝氨酸切肽键 |

ECM 降解的三种调控方式：

1. **局部激活**：如纤溶酶（plasmin）在血栓局部被 TPA 激活
2. **膜表面限制**：蛋白酶必须绑在膜上才活（如 uPA 必须结合膜受体）
3. **分泌抑制剂**：TIMPs 抑制 MMPs，Serpins 抑制丝氨酸蛋白酶

实验证据：阻断 uPA 受体后，肿瘤生长但不转移——说明蛋白酶在膜表面的局限化是肿瘤转移的关键。

## 八、常见误区

- "良性肿瘤也会变成恶性肿瘤"——不一定。良性肿瘤和恶性肿瘤是不同的生物学实体，不是所有良性都会恶变。
- "癌症是单基因病"——错。癌症需要多个突变逐步积累，是多基因、多步骤的过程。
- "癌基因是外来入侵的基因"——错。癌基因来源于自身正常的原癌基因（proto-oncogene），只是被异常激活了。
- "抑癌基因只要一个拷贝失活就会致癌"——错。抑癌基因需要两个拷贝都失活（二次打击）才会完全丧失功能。
- "Warburg 效应说明肿瘤细胞不用线粒体"——错。肿瘤细胞仍然使用线粒体，只是代谢比例偏向糖酵解，以便获取更多合成原料。
- "肿瘤转移是因为原发瘤长得太大撑破了"——错。转移是一个主动的、多步骤的生物学过程，涉及侵袭、血管内渗、存活、外渗和定植。
- "非编码 DNA 都没用"——错。非编码区域可能承担调控、结构等多种功能。

## 九、自测题

1. 良性肿瘤和恶性肿瘤最核心的区别是什么？

答题关键：

- 恶性肿瘤具有侵袭和转移能力，良性肿瘤没有。

2. 列举肿瘤单克隆起源的两个经典证据。

答题关键：

- 费城染色体（CML 中所有肿瘤细胞携带相同易位）
- X 染色体失活嵌合（肿瘤组织内所有细胞失活同一条 X）

3. 肿瘤的七大特征是什么？用一句话概括每一个。

答题关键：

- 基因组不稳定、分裂失控、Warburg 效应、凋亡减少、逃避衰老、侵袭转移、血管生成。

4. 癌基因和抑癌基因在突变类型和等位基因要求上有什么区别？

答题关键：

- 癌基因：功能获得，单个等位基因突变即足（显性）
- 抑癌基因：功能丧失，两个等位基因都要失活（隐性，二次打击）

5. 原癌基因可以通过哪四种方式被激活成癌基因？各举一个例子。

答题关键：

- 点突变（Ras）、截短（EGFR）、基因扩增（HER2）、染色体易位（BCR-ABL）

6. p53 在 DNA 损伤后是如何阻止细胞分裂的？

答题关键：

- DNA 损伤 → ATM/ATR → Chk1/Chk2 → 磷酸化 p53 → p53 激活 p21 → p21 抑制 Cdk → 细胞周期停滞

7. 为什么肿瘤发病率随年龄指数级上升？

答题关键：

- 肿瘤需要多个突变积累，年龄越大累积突变越多，达到致癌阈值的概率越高。

8. Warburg 效应中，肿瘤细胞为什么选择效率低的糖酵解而非高效的氧化磷酸化？

答题关键：

- 糖酵解速度快，且中间产物可作为合成 DNA、蛋白、脂质的原料，满足快速增殖需求。

## 十、考前速记版

- 肿瘤两大特性：**不受控增殖 + 侵袭转移**。
- 良性 vs 恶性的关键区别：**有无侵袭转移能力**。
- 单克隆起源证据：**费城染色体 + X 染色体失活嵌合**。
- 肿瘤本质：**多突变累积 + 微进化过程**。
- 七大特征口诀：**"不稳分代死老转血"**（不稳定、分裂失控、代谢异常、凋亡减少、不老/永生、转移、血管生成）。
- Warburg 效应：有氧条件下仍偏好糖酵解，为快速增殖提供合成原料。
- 三类肿瘤关键基因：**癌基因（油门卡死）、抑癌基因（刹车失灵）、基因组维护基因（修理工罢工）**。
- 癌基因：功能获得，**单个突变即足**；抑癌基因：功能丧失，**二次打击**。
- 原癌基因激活四种方式：**点突变、截短、基因扩增、染色体易位**。
- Rb：控制 E2F → 细胞周期；**二次打击假说**。
- p53：DNA 损伤 → p21 → Cdk 抑制 → 周期停滞或凋亡。**超过 50% 肿瘤有 p53 突变**。
- 肿瘤成因四大类：**生活方式、环境、致癌物、病毒/细菌**。
- 关键致癌病原体：**HPV-宫颈癌、HBV-肝癌、H. pylori-胃癌**。
- ECM 降解与转移：**MMP + 丝氨酸蛋白酶**，三种调控方式（局部激活、膜限制、抑制剂）。
- 最重要的可避免因素：**戒烟**（占癌死亡 29%）。
